目标是防倒卖，不是误伤正常家庭用户。教育场景下多设备、多地区、多成员使用是常态。

正常 家庭多设备、家长手机 + 孩子 iPad、家里和学校 IP 不同 允许
轻微异常 短时间跨城登录、同账号多设备同时播放 短信/微信验证
明显异常 高频更换设备、多账号同设备登录 踢下线 + 风险提示
高风险 同账号长期异地多人使用、批量倒卖特征 限制登录 / 冻结 / 人工审核

第一步：统一指标和口径

确认各渠道流量、留资、加微、上课、购课转化数据；明确加微率口径定义；识别当前最大卡点环节。

数据对齐口径确认

第二步：拆成两个项目并行推进

项目 A（增长转化）：落地页优化 + 状态短信 + 漏斗看板。项目 B（交易底座）：体验课/正价课 ID + H5 支付 + CCID 归因 + 自动植课。

第三步：MVP 最小闭环验证

先用一条产品线、一个课程包、一个 Level 范围跑通：落地页加微 → 状态短信 → 体验课 → 正价课支付 → CCID 归因 → 自动植课。

单线验证快速迭代

第四步：逐步扩展

验证转化提升和履约闭环有效后，再扩展到更多 Level、课程包、优惠券规则和风控策略。
